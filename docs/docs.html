Parameters (clap.params)

One automatable parameter:

IdNameRangeDefault
0Gain0.0 – 1.00.5

Incoming CLAP_EVENT_PARAM_VALUE events are applied in process() and flush(). When the GUI knob changes the gain, the plugin calls host->request_callback; on_main_thread then requests a process cycle, during which process() emits PARAM_GESTURE_BEGIN / PARAM_VALUE / PARAM_GESTURE_END to out_events so the DAW value tracks the knob.

GUI (clap.gui)

The plugin embeds a native child window into the host's editor:

  • Windows: Win32 child HWND, GDI painting, PNG artwork via pngload.pas.
  • Linux: X11 window, XReparentWindow embed, Xlib drawing, GuiPump for events.
  • macOS: Cocoa NSView subclass (Objective-C runtime + CoreGraphics).

If background.png and knob.png are present (loaded from the working directory) they are drawn; otherwise a generated knob is shown. The knob updates the gain on vertical drag.

The macOS Cocoa view is best-effort and must be verified on a Mac; the Windows and Linux builds are compile-verified.

State (clap.state)

save/load persist a 24-byte, version-2 record:

'C''H''S''1' | version(2) | gain(double) | width(uint32) | height(uint32)

So sessions and presets recall both the knob value and the window size. The magic + version are validated on load.

Building

CLAP (all targets)

./build_all.bat            # win64, linux-x64, macos-intel, macos-aarch64
./build_all.bat --check    # verify toolchain only

Artifacts land in dist/<target>/ and version-stamped copies in Deploy/.

VST3 (Windows, via clap-wrapper)

Clone the SDKs into deps/ (already done in this repo):

deps/clap          # CLAP SDK
deps/vst3sdk       # VST3 SDK 3.7.x (3.8.x fails on GCC)
deps/clap-wrapper  # clap-wrapper

build_all.bat then builds dist/win64/clap_skeleton.vst3 automatically (needs CMake + Ninja + a C++ compiler). macOS AU/VST3 and Linux VST3 are built with the same clap-wrapper command on those OSes.

Use VST3 SDK 3.7.x with GCC/MinGW — 3.8.x fails with an ambiguous iid. clap-wrapper is built with -Wno-deprecated-declarations.

Installing

CLAP

  • Windows: %LOCALAPPDATA%\Programs\Common\CLAP\
  • Linux: ~/.clap/ or /usr/lib/clap/
  • macOS: ~/Library/Audio/Plug-Ins/CLAP/ or /Library/Audio/Plug-Ins/CLAP/

VST3

  • Windows: C:\Program Files\Common Files\VST3\
  • Linux: ~/.vst3/ or /usr/lib/vst3/
  • macOS: ~/Library/Audio/Plug-Ins/VST3/ or /Library/Audio/Plug-Ins/VST3/

Rescan plugins in your DAW. The plugin appears as Chameleon Skeleton.
