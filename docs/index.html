What It Is

ChameleonSkeleton is a working CLAP audio-effect plugin written entirely in FreePascal/Lazarus. It is a channelstrip-style skeleton: one automatable Gain parameter, a bitmap-based GUI, and session state — wired to a passthrough DSP you replace with your own.

The plugin is built as a plain library (a .clap on Windows/Linux, a .clap bundle on macOS) and can be wrapped into VST3 with clap-wrapper. Your DSP stays in Pascal; the format/GUI shell is handled by the build.

Why CLAP first? CLAP is a modern, open (MIT) plugin ABI with a clean C interface. One CLAP build + clap-wrapper yields VST3 (and AUv2 if you add the Apple SDK) — the widest reach for the least work.

Features

CLAP Params

One automatable Gain parameter with count / get_info / get_value / value_to_text / text_to_value / flush. GUI edits notify the host via request_callback → on_main_thread → PARAM_VALUE events.

Bitmap GUI

Native embedded window: Win32 (GDI), Linux (X11), macOS (Cocoa NSView). Loads background.png / knob.png if present, otherwise draws a generated knob.

State

clap.state save/load persists the gain and window size (24-byte versioned record) so sessions and presets recall the knob.

Pascal DSP

Your DSP lives in plugin_process. The format and GUI shell is C ABI glue — no C++ needed for the audio path.

One Build

build_all.bat builds CLAP for win64/linux-x64/macos-intel/macos-aarch64, stages dist/, copies version-stamped artifacts to Deploy/, and builds the Windows VST3 via clap-wrapper.

Open & Forkable

MIT-licensed sources. Fork it, drop in your DSP and artwork, and ship your own plugin.

Build

Requirements: FreePascal (FPC) with cross-compilers, CMake + Ninja + a C++ compiler (for the VST3 wrapper), and the SDKs cloned into deps/.

./build_all.bat            # all targets + Deploy/ + Windows VST3
./build_all.bat --check    # verify the toolchain only
NO_VERSION_BUMP=1 ./build_all.bat   # keep the current version

See the documentation for the full layout, parameters, GUI, and state format.
