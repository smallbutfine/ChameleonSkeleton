这是什么

ChameleonSkeleton 是一个功能完整的 CLAP 音频效果插件，完全用 FreePascal/Lazarus 编写。它是一个通道条骨架：一个可自动化的 Gain 参数、一个位图 GUI 和会话状态，连接到你可以替换为自己的直通 DSP。

该插件编译为普通库（Windows/Linux 上是 .clap，macOS 上是 .clap 包），可通过 clap-wrapper 封装为 VST3。你的 DSP 保持 Pascal；格式/GUI 外壳由构建处理。

CLAP — CLAP 优先。通过 clap-wrapper 生成 VST3。位图 GUI。DSP 无需 C++。
